# CLI + Kanban Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `npx novaplan` work end-to-end: AI coding agent installs CLI, reads task list, marks tasks/subtasks in_progress/completed/failed, and kanban board cards move live.

**Architecture:** Database migration adds `feature_name`, `started_at`, `completed_at` to `tasks`; `saveTaskTree` writes one row per TASK (not per feature) with subtask status in jsonb. Five API endpoints fixed/written. CLI adapted from Next.js skeleton at `packages/cli/`. Prompt template rewritten with CLI install + command reference. Two nav buttons added.

**Tech Stack:** TypeScript, Drizzle ORM, PostgreSQL, Commander 12 + Chalk 5 (ESM), npm publish, TanStack Start file-based routing.

## Global Constraints

- Local-only: `http://localhost:3000` hardcoded as default API URL. No production domain.
- npm package name: `novaplan` (not `novaplan-cli`).
- All 4 existing status values remain: `pending`, `in_progress`, `completed`, `failed`.
- Subtask status stored inside jsonb `subtasks` array, each entry gets `{ ..., status: "pending"|"in_progress"|"completed"|"failed" }`.
- `started_at` set when status transitions to `in_progress`; `completed_at` set when status transitions to `completed` or `failed`.
- `feature_name` text column on `tasks` table (nullable, default null for backwards compat).
- TanStack Start route pattern: `createFileRoute(...)` with `server: { handlers: { METHOD } }`.
- Button styling: `btn-primary px-3 py-1.5 rounded-md text-xs font-[510]` (matches existing kanban link).
- `Link` import: `from "next/link"` via `@/lib/next-compat/link` shim (matches existing pattern).
- No drag-and-drop. Status changes via CLI/API only. Kanban auto-polls every 10s.
- Drizzle migration via `pnpm db:generate` then `pnpm db:push` (existing workflow).

- [ ] **Step 1: Update `saveTaskTree`**

Replace the save logic (lines 55-94). New behavior:
- Delete all tasks for projectId (same as before)
- Loop features → loop tasks within each feature
- Insert ONE row per task (not per feature):
  - `id`: `crypto.randomUUID()`
  - `projectId`
  - `title`: task name (not feature name)
  - `description`: task description
  - `featureName`: feature name
  - `subtasks`: JSON array of `{ name, description, details, status: "pending" }`
  - `status`: `"pending"`
  - `order`: sequential counter across all features

```ts
export async function saveTaskTree(
  projectId: string,
  taskTree: TaskTree,
): Promise<{ success: boolean; error?: string }> {
  try {
    await db.delete(tasks).where(eq(tasks.projectId, projectId));

    let order = 0;
    for (const feature of taskTree.features) {
      for (const task of feature.tasks) {
        const subtaskRows = task.subtasks.map((s) => ({
          name: s.name,
          description: s.description,
          details: s.details ?? [],
          status: "pending" as const,
        }));
        await db.insert(tasks).values({
          id: crypto.randomUUID(),
          projectId,
          title: task.name,
          description: task.description || null,
          featureName: feature.name,
          status: "pending",
          subtasks: subtaskRows,
          order: order++,
        });
      }
    }

    const [proj] = await db.select({ step: projects.step }).from(projects).where(eq(projects.id, projectId)).limit(1);
    const updateData: Record<string, unknown> = { taskStatus: "completed", updatedAt: new Date() };
    const next = advanceStep(proj?.step, "task");
    if (next) updateData.step = next;
    await db.update(projects).set(updateData).where(eq(projects.id, projectId));
    return { success: true };
  } catch (error) {
    const msg = error instanceof Error ? error.message : String(error);
    console.error("saveTaskTree error:", msg);
    return { success: false, error: msg };
  }
}
```

- [ ] **Step 2: Update `getTaskTree`**

Replace the read logic (lines 99-135). New behavior:
- Select `title`, `description`, `featureName`, `subtasks` from tasks ordered by `order`
- Group rows by `featureName` to rebuild features
- Each row's subtasks already has status in jsonb

```ts
export async function getTaskTree(projectId: string): Promise<TaskTree | null> {
  try {
    const rows = await db
      .select({
        title: tasks.title,
        description: tasks.description,
        featureName: tasks.featureName,
        subtasks: tasks.subtasks,
      })
      .from(tasks)
      .where(eq(tasks.projectId, projectId))
      .orderBy(asc(tasks.order));

    if (rows.length === 0) return null;

    const featureMap = new Map<string, TaskTree["features"][number]>();
    for (const row of rows) {
      const fname = row.featureName || "Umum";
      if (!featureMap.has(fname)) featureMap.set(fname, { name: fname, tasks: [] });

      const subtasks = Array.isArray(row.subtasks)
        ? (row.subtasks as Array<{ name: string; description: string; details?: string[]; status?: string }>)
            .map((s) => ({ name: s.name, description: s.description || "", details: s.details ?? [] }))
        : [];

      featureMap.get(fname)!.tasks.push({
        name: row.title,
        description: row.description || "",
        subtasks,
      });
    }

    return { features: Array.from(featureMap.values()) };
  } catch (error) {
    console.error("getTaskTree error:", error);
    throw error;
  }
}
```

- [ ] **Step 2: Fix `POST /api/v1/subtasks/$id/status.ts` — replace 501 stub**

Current: 15 lines, always returns 501. Replace entirely. The `id` param is the parent task UUID. Body includes `subtaskIndex` (0-based index in subtasks jsonb array) and `status`.

```ts
import { createFileRoute } from "@tanstack/react-router";
import { eq } from "drizzle-orm";
import { db } from "@/db";
import { tasks } from "@/db/schema";
import { apiKeyAuth, hasScope, verifyProjectOwnership } from "@/lib/api-key-auth";

const VALID_STATUSES = ["pending", "in_progress", "completed", "failed"];

export const Route = createFileRoute("/api/v1/subtasks/$id/status")({
  server: {
    handlers: {
      POST: async ({ params, request }: { params: { id: string }; request: Request }) => {
        const auth = await apiKeyAuth(request);
        if ("error" in auth) return Response.json({ error: auth.error }, { status: auth.status });
        if (!hasScope(auth, "write:subtask:status")) return Response.json({ error: "Insufficient scopes" }, { status: 403 });

        const taskId = params.id;
        let body: Record<string, unknown>;
        try { body = await request.json(); }
        catch { return Response.json({ error: "Invalid JSON body" }, { status: 400 }); }

        const { subtaskIndex, status } = body as { subtaskIndex?: number; status?: string };
        if (typeof subtaskIndex !== "number" || subtaskIndex < 0)
          return Response.json({ error: "subtaskIndex must be a non-negative integer" }, { status: 400 });
        if (!status || !VALID_STATUSES.includes(status))
          return Response.json({ error: `Invalid status. Must be one of: ${VALID_STATUSES.join(", ")}` }, { status: 400 });

        const [task] = await db.select({ id: tasks.id, projectId: tasks.projectId, subtasks: tasks.subtasks })
          .from(tasks).where(eq(tasks.id, taskId)).limit(1);
        if (!task || !(await verifyProjectOwnership(auth.userId, task.projectId)))
          return Response.json({ error: "Task not found" }, { status: 404 });

        const subs = Array.isArray(task.subtasks) ? [...task.subtasks] : [];
        if (subtaskIndex >= subs.length)
          return Response.json({ error: `subtaskIndex ${subtaskIndex} out of range (0-${subs.length - 1})` }, { status: 400 });

        subs[subtaskIndex] = { ...subs[subtaskIndex], status };
        await db.update(tasks).set({ subtasks: subs, updatedAt: new Date() }).where(eq(tasks.id, taskId));

        return Response.json({ taskId, subtaskIndex, status });
      },
    },
  },
});
```
